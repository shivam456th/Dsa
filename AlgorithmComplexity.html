Algorithm Complexity (Big O Notation)

Big O notation ka use hum yeh batane ke liye karte hain ki koi algorithm input size badhne par kitna slow ya fast hota hai. Yeh mainly Time Complexity aur Space Complexity ko measure karta hai.

Time Complexity Name Example Performance
O(1) Constant Time Accessing array element by index 🚀 Very Fast
O(log n) Logarithmic Time Binary Search ⚡ Fast
O(n) Linear Time Linear Search 🙂 Average
O(n log n) Linearithmic Time Merge Sort, Quick Sort 👍 Efficient
O(n2) Quadratic Time Bubble Sort, Selection Sort 🐢 Slow
Important Notes:
  • Big O worst-case scenario ko represent karta hai
  • Loops aksar O(n) banate hain
  • Nested loops usually O(n²) hote hain
  • Efficient algorithms large data ke liye zaroori hote hain
